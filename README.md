# 🎬 TMDB Movie Analytics

## 📌 Project Overview
An end-to-end movie data analytics project to understand **movie performance, revenue, ratings, popularity, genres, actors, directors, and keywords**.

## 🎯 Objectives
- 🧹 Clean and preprocess movie data
- 🗄️ Store cleaned data in MySQL
- 🐼 Perform analysis using Pandas
- 🔎 Analyze business questions using SQL
- 📊 Perform EDA using Matplotlib & Seaborn
- 📈 Build an interactive Power BI dashboard

## 🛠️ Tools & Technologies
🐍 Python | 🐼 Pandas | 🔢 NumPy | 📊 Matplotlib | 🎨 Seaborn | 🗄️ MySQL | 🔌 PyMySQL | 📈 Power BI

## 🧩 Project Workflow
`Raw Data → Data Cleaning → MySQL → Pandas Analysis → SQL Analysis → EDA → Power BI`

## Analysis
### Pandas
- Profit & ROI analysis
- Movies released by year
- Runtime outliers
- Genre popularity
- Top actors
- Duplicate titles
- Popularity patterns

### SQL
- Action movies after 2015
- Top highest-grossing movies
- Revenue & budget by genre
- Top actors and directors
- Top keywords
- Above-average budget / below-average revenue movies
- Christopher Nolan movie actors
- Highest-rated genres

### EDA
- Budget, runtime & rating distributions
- Budget vs Revenue
- Vote Count vs Popularity
- Rating by Status
- Runtime vs Rating
- Genre, Rating & Popularity
- Language & Movie Status

##  Power BI Dashboard
The dashboard contains:
- 💰 Revenue & budget insights
- ⭐ Rating analysis
- 🎬 Movie release trends
- 🎭 Genre analysis
- 🌍 Language analysis
- 👥 Actor & movie insights
- 📊 Interactive business visuals

## 💡 Key Takeaway
The project combines **Python, SQL, MySQL, EDA, and Power BI** to transform raw movie data into meaningful business insights.
